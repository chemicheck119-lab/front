# 물질 검색에서 대응 자료까지

2026-10-07. 별도의 CAS 재입력·처리 건수 패널을 제거하고 기존 물질 검색을 사용한다.

- 사고 접수 없이 물질명 또는 CAS 검색 → 오른쪽 대응 참고자료 자동 조회.
- 사고물질 확인이 저장되면 같은 CAS의 참고자료 자동 조회. 검색값은 현장 확인 기록으로 승격하지 않는다.
- 화재·누출·응급조치·노출방지·안정성 항목을 큰 버튼으로 선택한다. LLM이 새 지침을 생성하거나 원문을 자르지 않는다.
- 근거·수집 시각·선택 버전은 펼쳐서 확인한다. 처리 건수·checksum·승인 작업은 사용자 화면에서 제외했다.
- 미제공 항목, 승인 대기, 연결 오류를 구분한다. 자료 없음은 안전을 의미하지 않는다. 기존 두 CAS 게이트를 통한 충돌 검토는 그대로 유지한다.

`VITE_ENABLE_APPROVED_REFERENCE=true`를 명시한 환경에서 켜진다. 개발 Vite proxy `/local-reference`는 loopback 자료 서버 8004로 전달한다. production build에도 컴포넌트는 있지만 해당 경로를 실제 인증된 BFF reverse proxy로 연결해야 하며, 이 변경으로 Spring BFF를 배포한 것은 아니다. 실패 시 기존 합성 검색으로 자동 대체하지 않는다. flag가 false면 기존 검색 경로를 유지한다. `referenceLab=1` URL 매개변수는 더 이상 필요하지 않다.

현재 로컬 연결은 보관 KOSHA 메틸 알코올 1종과 CAS 67-56-1의 정확 일치 조회에 한정한다. 임의 표현·미확인 이명을 자동으로 동일 물질로 매핑하지 않는다. 여러 물질·불명확한 표현은 기존 Resolver의 후보 선택 흐름과 승인 자료 카탈로그 확장이 추가로 필요하다. 실제 원천 후보는 사람 승인 전까지 본문을 제공하지 않는다.

검증: 승인된 합성 fixture 원문 끝부분 유지, 미제공 항목 표시, 미승인 본문 차단, 연결 실패 시 합성 대체 없음, 변경된 검색의 이전 요청 취소. 실제 브라우저에서는 검색 67-56-1 → 해당 물질명 → 승인 대기 표시를 확인했다. 현직 소방대원 사용성·장갑 착용 조작성·현장 대응 효과를 검증한 것은 아니다.
