# 단계형 공개 합성 시연 QA

## 접속

- FE: `https://chemicheck119.site`
- BFF: `https://chemicheck119-be-staging-w6s6lwanpa-du.a.run.app`
- 권장 화면: 가로 1024×768 이상

상단에 `실제 API`와 `인증 미사용`이 보여야 합니다. `시연 데이터`가 보이면 offline fixture
환경이므로 Live QA 증적으로 사용하지 않습니다.

## 단계별 실행

1. 좌측 `상황실 연결`을 열고 `지령망 연결`을 누릅니다.
2. `연결 중` 뒤 `새 지령 수신`과 BE 요청 ID가 표시되는지 확인합니다.
3. 지령 내용을 읽고 `지령 확인 및 대응화면에 반영`을 누릅니다.
4. 시설명·주소·신고문이 입력됐지만 분석 결과는 아직 없는지 확인합니다.
5. 사고 분석 버튼을 눌러 실제 FE → BE → AI 후보 분석을 실행합니다.
6. 사고물질과 시설물질을 각각 별도의 현장 확인 화면에서 저장합니다.
7. 확인 2/2 이후에만 CAMEO 규칙과 위험 카드가 표시되는지 확인합니다.

지령 수신, 대원 확인, AI 분석, 현장 확인은 서로 다른 행동이어야 합니다. 한 버튼이 여러 단계를
자동 실행하면 이 QA에서는 실패입니다.

## 통과 조건

| 단계 | 서버 동작 | 화면 통과 조건 |
|---|---|---|
| 지령망 연결 | BE SSE `incident.accepted` | 연결 상태와 공개 합성 신고 고지·요청 ID 표시 |
| 대원 확인 | 로컬 대응화면 반영 | 시설·주소·신고문만 입력, AI 분석은 미실행 |
| AI 후보 | FE → BFF → AI | 확인 0/2, 규칙 잠김, 위험 카드 비공개 |
| 사고물질 확인 | confirmation 저장 후 재분석 | 확인 1/2, 규칙 잠김 |
| 시설물질 확인 | confirmation 저장 후 재분석 | 확인 2/2 이후에만 CAMEO 규칙 실행 |

## 실패 시 증적

- 실패한 단계와 화면의 요청 ID
- 브라우저 Network의 요청 URL·HTTP 상태·응답 `error.code`
- 실행 시각(Asia/Seoul)
- 화면 전체 스크린샷

실패를 offline fixture 성공으로 바꾸지 않습니다. 다시 시도할 때는 새 SSE incidentId부터
시작합니다.
