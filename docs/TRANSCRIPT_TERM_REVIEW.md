# 통화 전사의 용어 검토 보조

## 기존 구현과 문제

전화 전사는 BFF의 인증된 SSE로 수신하고 INTERIM과 FINAL을 구분한다. FINAL은 사용자가 수정한 뒤 `expectedRevision`을 포함해 승인해야 분석할 수 있다. 기존 textarea 직접 수정은 유지했다.

사용자는 실제 통화 전사가 사이트에 전달됐고 일부 단어가 불명확했다고 설명했다. 이번 작업에 실제 음성/원문/정답 기록은 제공되지 않았으므로 특정 실제 오류의 원인이나 개선율을 확정하지 않았다.

관련 speech-service README에는 기존 hotword 실험 및 LoRA 학습 기록이 있다. clean 평가의 개선 후보 신호와 별개로 wind 조건에서 WER 악화 등으로 후보를 기각하고 기준선을 유지했다고 기록돼 있다. ClawOps의 공급자 전사와 별도 Whisper 서비스의 학습은 다른 경로다. 이번 작업은 이 모델을 교체하거나 학습하지 않는다.

## 최소 변경

- 최종 전화 전사 검토에 `TranscriptTermReview`를 연결했다.
- 염산·황산·수산화나트륨·차아염소산나트륨의 정확한 문자 배열에서 띄어쓰기 변형만 제안한다.
- 수신 원문과 수정 초안을 분리한다. 원문은 펼쳐 확인할 수 있으며 제안이 초안을 자동 변경하지 않는다.
- 사용자가 개별 후보 적용을 누른 뒤 기존 승인 API로 저장한다. 승인 응답의 정확한 revision을 분석에 전달한다.
- `염 선`, 수소/산소처럼 뜻이 다른 오인식은 추정하지 않는다. 모르는 단어의 개선을 해결한 기능이 아니다.
- 부정·불확실 표현, 조사와 나머지 문장을 보존한다. CAS/시설 물질 확인·충돌 분석 게이트를 변경하지 않는다.
- API 계약/백엔드/모델/유료 통화/운영 환경은 변경하지 않았다.

## 검증

```sh
corepack pnpm test src/features/speech/TranscriptTermReview.test.tsx src/pages/IntegratedMainPage.phone.test.tsx
node -e 'console.log(require("node:path").join(require("node:os").tmpdir(), "chemicheck119-transcript-review/paired-results.json"))'
corepack pnpm check
```

동일 합성 전사문 6건: 띄어쓰기 후보 3건, 올바른 전사/불확실 표현 3건. 후보 선택을 모의한 뒤 3건의 표기가 고정 기대값과 일치했고 나머지 3건은 그대로 유지됐다. 이것은 사전에 정의한 기능 예제의 결과이며 독립 음성 test 정확도나 CER/WER 개선율이 아니다. 입력 hash와 건별 결과는 `measurement/transcript-paired-results.json`에 저장한다.

주 화면 통합 테스트는 합성 SSE 수신 → 원문 보존 → 사용자 후보 선택 → 승인 API의 text/revision → 분석 요청의 승인 text/revision을 대조한다. 선택 전과 승인 전 분석이 호출되지 않는지 확인한다. 실제 BFF DB 저장/전화 공급자/사람의 판단 품질은 이번 mocked API 테스트로 증명하지 않는다.

## 자기소개서 근거

새 구현 및 테스트 실행 주체: AI. 사용자가 기존에 수행했다고 설명한 ClawOps 연결·음성 데이터 정제와 이 추가 구현의 기여를 합치지 않는다.

확인 가능한 문장: “ClawOps를 연결해 통화 내용을 사이트에 전사했다. 일부 용어가 불명확하다는 문제를 바탕으로, 원문을 보존하고 사용자 검토 후 수정문을 전달하는 흐름으로 개선을 확장했다.” 새 기능의 직접 구현을 사용자의 기여로 쓸 때는 실제 담당 작업을 별도로 명시해야 한다.

사용 불가: “전화 모델을 추가 학습해 정확도를 향상했다”, “실제 음성 오류 3건을 제거했다”, “정확도 100%”, “수동 검토 시간 감소”.

후속 검증: 동의받은 비민감 음성, 사람 정답, 오류 종류를 고정하고 기존/변경 경로를 같은 입력으로 비교해야 한다. ClawOps 공급자 모델에 이 후처리를 적용한 것이 아니라 수신 이후 검토 보조를 추가한 것이다. 현업 도메인 평가 및 승인 시간이 포함된 성과 측정은 미실행이다.
