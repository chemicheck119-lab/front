# 좌측 현장 도구 설계

좌측 패널은 페이지 이동 메뉴가 아니라 출동 중 1~2번의 터치로 사용하는 현장 도구입니다. 아무 동작도 하지 않는 버튼, 가짜 전화번호, 후보를 확정값처럼 보이게 하는 링크를 두지 않습니다.

## 1. 상황실 연결

- 버튼은 연결 대상과 전화번호를 먼저 확인하는 Dialog를 엽니다.
- 전화번호가 있으면 `tel:` 링크와 번호 복사를 제공합니다.
- 전화번호가 없으면 `연락처 미설정`을 표시하고 가짜 번호나 일반 119 번호로 대체하지 않습니다.
- 통화 내용을 녹음하지 않으며 전화 연결 시도만 현재 사고 기록에 남깁니다.

현재는 다음 공개 환경변수를 임시로 지원합니다.

```text
VITE_DISPATCH_CENTER_NAME=
VITE_DISPATCH_CENTER_PHONE=
```

실제 운영에서는 인증된 로그인 세션에서 조직별 연락처를 받아야 합니다.

## 2. 공식 화학자료

사고 분석의 역할별 후보 CAS를 표시하고, 각 후보마다 다음 동작을 제공합니다.

- CAS 번호 복사
- 안전보건공단 KOSHA MSDS 검색
- 화학물질종합정보시스템 검색
- 운송 화학사고일 때 ERG 2024 확인

후보는 `후보·확인 필요`, 현장 확인 게이트를 통과한 역할만 `현장 확인됨`으로 표시합니다. KOSHA 검색 자료는 참고용이며 현장 제품의 제조·수입·판매자가 제공한 MSDS와 용기 라벨을 우선합니다.

## 3. 현재 사고 기록

과거 기록 검색보다 현재 사고가 안전하게 저장되고 있는지를 우선합니다.

- 대화·상태 메시지
- 분석 ID 개수
- 현장 확인 ID 개수
- 미저장 합계
- 시각·작성 주체·내용 타임라인
- 기존 대응 기록 저장 Dialog 연결

저장 성공 전까지 화면의 기록을 유지하며, 저장 성공과 `resetAllowed=true` 이후에만 새 사고로 초기화합니다.

## 4. 하단 운영 상태

- 데이터 모드: 실제 API / 캐시 / 시연 / 설정 필요
- GPS 상태와 최신성 설명
- 미저장 기록 건수

`실제 API 설정`은 서버의 실시간 건강 상태를 보장한다는 뜻이 아닙니다. 향후 heartbeat 또는 세션 API가 생기기 전에는 `서버 연결 정상`이라고 표시하지 않습니다.

## 접근성과 색상

- 주요 도구 버튼 높이는 58px, Dialog 동작은 44px 이상입니다.
- 키보드 focus ring과 접근 가능한 이름을 제공합니다.
- Dialog를 열면 닫기 버튼에 focus를 두고, Escape로 닫은 뒤 호출한 도구 버튼으로 focus를 돌려줍니다.
- 빨강은 전화 버튼이나 일반 메뉴가 아니라 실제 위험 상태에만 사용합니다.
- 후보와 확인 완료 상태는 색상뿐 아니라 텍스트로 함께 구분합니다.
